# first-model

⚡️ Cấu hình cơ bản Webpack cho phát triển ứng dụng JavaScript/TypeScript hiện đại.  
Mục tiêu: nhanh, dễ mở rộng, có sẵn loader và plugin thường dùng.

---

## ✨ Tính năng

- Webpack 5 cấu hình sẵn từ đầu
- Hỗ trợ **TypeScript** và **JavaScript**
- Hỗ trợ **CSS / SCSS / PostCSS**
- Tích hợp **Babel** để build ES6+
- Dev server với **Hot Module Replacement (HMR)**
- Tối ưu output (splitChunks, hash, clean dist,…)
- Source map cho môi trường dev
